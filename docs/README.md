<h1 align="center">Bamah docs</h1>
<p align="center">Making characters, putting them in a scene together, and reading what they feel.</p>

These pages are how Bamah works, written down. It's a stage for the characters of a story: you make them, put them in a scene, and watch how each of them reacts, with whichever AI model you like. If something here doesn't match what Bamah does, Bamah wins, and I fix the page.
